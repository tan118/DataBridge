
# DataBridge

### CSV ETL & Data Quality Platform

DataBridge is a Python-based ETL platform designed to
ingest CSV files, validate data, clean inconsistencies,
and load structured records into a PostgreSQL database.

## Key Features

- CSV file ingestion
- Data preview and profiling
- Missing value detection
- Duplicate record detection
- Data cleaning and transformation
- PostgreSQL integration
- Interactive analytics dashboard

## Technology Stack

- Python
- Pandas
- NumPy
- Streamlit
- PostgreSQL
- SQLAlchemy
- Plotly
